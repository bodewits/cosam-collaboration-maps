# COSAM Research Collaboration Maps

Public, interactive maps of Auburn University College of Sciences and Mathematics research collaborations documented in a Web of Science export for 2021–2025. Temporal counts retain all source records, including contributions by current personnel, students, alumni, and former personnel; they are not filtered to the current roster.

- `world.html` shows international collaboration intensity by country.
- `us.html` shows domestic collaboration intensity by state.
- `index.html` provides a tabbed interactive viewer for both maps and is the preferred shareable URL.

The site contains aggregate collaboration data only. It does not include private faculty metrics or review records.
